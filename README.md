# «Тьма рассеется»

Статическая версия информационного сайта, подготовленная для публикации через GitHub Pages.

## Состав

- главная страница `index.html`;
- справочник `guide.html`;
- отдельная страница правовой информации `legal.html`;
- локальные стили, сценарии, изображения и шрифты;
- шесть материалов, доступных по ссылкам со страницы справочника.

Сайт не требует сборки, сервера приложений или базы данных. Для GitHub Pages используется ветка `main`, каталог `/ (root)`.

## Лицензии
